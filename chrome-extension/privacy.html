Nesmi Chrome extension privacy

Effective October 16, 2026. Empathie, Inc.

The extension stores only the chore text you enter, completion status, and random task identifiers locally in this browser profile. This supports your private checklist. No account is required. It does not transmit tasks, collect analytics, read websites, browsing history, cookies, or passwords, or share or sell your data. No remote code is loaded.

Tasks remain until you delete them or remove the extension. Delete individual tasks using their delete buttons; mark and clear all tasks to erase the checklist. Local browser storage is not an encrypted vault; avoid sensitive information. Anyone with access to this browser profile may access the checklist.

The optional Open Nesmi website link opens https://empathie.ai/nesmi/ in a new tab. Website requests and any website account use are separate from this extension; no checklist data is passed to the website. Website privacy terms apply there.
