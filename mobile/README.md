# Chorely iOS + Android wrapper

This isolated Capacitor wrapper provides one native shell for both iOS and Android without changing the existing web build or Supabase configuration.

Run `npm install`, then `npm run add:ios` and/or `npm run add:android`; use `npm run sync` after web changes. The wrapper opens the current production Chorely web app over HTTPS.

Publishing to App Store / Google Play still requires owner signing credentials, store records, screenshots, privacy declarations, and review.
